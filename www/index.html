Hubungkan akun

Cara mendapat token dan ID akun
  1. Buka app.metaapi.cloud di browser HP dan daftar.
  2. Tambah akun MetaTrader: isi nomor akun Exness, password, dan nama server (contoh: Exness-MT5Trial). Tipe MT4 atau MT5 sesuai akunmu.
  3. Tunggu status akun menjadi DEPLOYED, lalu salin ID akunnya.
  4. Buka halaman Token di MetaApi, buat API token, salin ke sini.
Password akun Exness hanya diisi di MetaApi, tidak masuk ke app ini. Coba dulu dengan akun demo.
